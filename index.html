DATOS LOCALES

Importar fuentes

Selecciona cada archivo. El catálogo y las listas se leen en este navegador; la colección permanece en IndexedDB local y no se envía a ningún servidor.

Catálogo público de RiftHuntDescarga las cartas en JSON; la colección y las listas no se envían.

El catálogo de RiftHunt se consulta como máximo una vez al día. La búsqueda usa TopDeck.gg y requiere una clave gratuita configurada en el servidor local. Las listas encontradas solo permanecen en memoria durante esta sesión.

Ver ejemplo de estructura
{
  "cards": [{
    "id": "ogn-001", "oracle_id": "card-001",
    "name": "Nombre de carta", "type": "Unit",
    "domains": ["Fury"], "energy": 2, "power": 1,
    "might": 3, "keywords": [], "tags": [],
    "rules_text": "Texto de efecto"
  }],
  "decks": [{
    "id": "lista-1", "name": "Lista de ejemplo",
    "legend": "Nombre de leyenda", "champion": "Nombre de campeón",
    "event": "Torneo", "date": "2026-10-01", "placement": 1,
    "cards": [{"card_id": "ogn-001", "quantity": 3}]
  }]
}

CSV de colección: card_id,quantity

Los nombres de campos alternativos comunes (printing_id, oracle_id, cardId, count, text) también se reconocen. Cada lista debería incluir la leyenda, las cartas y cantidades.

Puedes cargar uno o varios archivos.
